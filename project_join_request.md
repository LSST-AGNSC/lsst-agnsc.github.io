A list of all ongoing projects can be found within the [AGN SC Project Database](http://agnsc.udp.cl).

If you wish to join an active project, please complete the form below. Include your contact information, project identifiers, and any relevant interests, skills, or experiences you feel would contribute to the project.

Once submitted, the form's response will be sent directly to the project leader, who will reach out to you with next steps.

**Project Details**

- Project ID *(required)*

**Participation Details**

- Intended Contributions *(required)*  
  Please describe your intended contributions to the project. Consider sharing specific skills, expertise, or areas where you would like to be involved.
- Comments  
  Any additional comments or information for the project leader.
