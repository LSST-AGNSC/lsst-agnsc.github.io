Use this form to request to join an ongoing project of the LSST AGN Science Collaboration.

Ongoing projects are listed in the [LSST AGN SC Project Database](https://agnsc.udp.cl/), the collaboration's OpenProject system. The [AGN SC OpenProject User's Guide](/documents/) describes how projects are created, announced and tracked there, and how members are added to a project.

Each submission will be directed to the appropriate team for prompt review and follow-up.
